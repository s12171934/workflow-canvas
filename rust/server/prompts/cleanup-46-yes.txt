**마무리 보고 뒤 종료한다.** 보고를 `@@0@@/report.md` 에도 저장하고 실행 로그 `report` 를 보낸 뒤, 자기 터미널(`$ORCA_TERMINAL_HANDLE`)을 `orca terminal close --terminal <handle>` 로 닫는다. 실패한 단계·남은 확인·남긴 워크트리가 있어도 닫는다 — 그것은 보고와 실행 로그에 남고, 사용자는 캔버스에서 다시 실행한다. 닫지 않고 기다리는 것은 사용자 결정이 아직 열려 있을 때뿐이다(그때는 실행이 끝나지 않았다). 닫지 못하면 캔버스 서버가 실행 종료 뒤 대신 닫는다.
